# Diagramas C4

Vistas del [modelo C4](https://c4model.com/) de Simon Brown. Los diagramas usan la notación de C4
dibujada con Mermaid para que se versionen como texto junto al código.

!!! note "Estado"
    Estos diagramas describen la **arquitectura objetivo** de la fase 0–1 de
    [`deploy/`](https://github.com/PrometheusQuant/prometheus-platform/tree/develop/deploy). Cada
    contenedor indica si ya existe o qué ticket lo construye.

## Nivel 1: contexto del sistema

Quién usa la plataforma y con qué sistemas externos habla.

## Nivel 2: contenedores

Las piezas que se despliegan por separado. El código de dominio y de aplicación es **uno solo**
(monolito modular, [ADR-0001](../adr/0001-monolito-modular-hexagonal.md)): el proceso live, el
pipeline y la CLI importan el mismo paquete `prometheus_platform` con distintos puntos de entrada.

```mermaid
flowchart TB
    quant["<b>Quant</b><br/>[Persona]"]

    subgraph pq["PrometheusQuant"]
        direction TB
        cli["<b>CLI pq</b><br/>[Contenedor: Python · api]<br/>Ingesta, backtests y operación manual<br/><i>PQ-20</i>"]
        live["<b>Proceso live</b><br/>[Contenedor: Python + NautilusTrader]<br/>strategies → portfolio_risk → execution<br/>con kill-switch<br/><i>épica PQ-7</i>"]
        pipeline["<b>Pipeline de datos</b><br/>[Contenedor: Dagster]<br/>Assets bronze → silver → gold<br/>con checks de calidad<br/><i>PQ-22</i>"]
        lakehouse[("<b>Lakehouse</b><br/>[Contenedor: Parquet + DuckDB/DuckLake]<br/>Velas, funding y métricas point-in-time<br/><i>ADR-0003</i>")]
        postgres[("<b>PostgreSQL</b><br/>[Contenedor: base de datos]<br/>Journal de eventos append-only,<br/>backend de MLflow/Optuna")]
        mlflow["<b>Registro de experimentos</b><br/>[Contenedor: MLflow + Optuna]<br/>Cuenta todos los ensayos (N)<br/><i>PQ-24</i>"]
        dashboards["<b>Dashboards</b><br/>[Contenedor: Grafana · Streamlit · Power BI]<br/>Operación, exploración y BI<br/><i>épicas PQ-8, PQ-10</i>"]
    end

    binance["<b>Binance</b><br/>[Sistema externo]"]
    telegram["<b>Telegram</b><br/>[Sistema externo]"]

    quant -- "Ejecuta comandos" --> cli
    quant -- "Consulta" --> dashboards
    cli -- "Lanza ingestas y backtests" --> pipeline
    pipeline -- "Descarga Data Vision<br/>(checksum SHA-256) [HTTPS]" --> binance
    pipeline -- "Escribe Parquet" --> lakehouse
    pipeline -- "Registra ensayos" --> mlflow
    mlflow -- "Persiste" --> postgres
    live -- "Lee features gold" --> lakehouse
    live -- "Mercado y órdenes [WSS/HTTPS]" --> binance
    live -- "Append de eventos" --> postgres
    live -- "Alertas [structlog → bot]" --> telegram
    dashboards -- "Lee vistas (CQRS)" --> postgres
    dashboards -- "Lee tablas gold" --> lakehouse
```

## Correspondencia con los módulos (ADR-0001)

| Contenedor | Paquetes de `prometheus_platform` |
|---|---|
| CLI `pq` | `api` → `data_platform`, `research` |
| Proceso live | `strategies`, `portfolio_risk`, `execution`, `adapters` (Binance, paper) |
| Pipeline de datos | `data_platform`, `research`, `adapters` (Data Vision, persistencia) |
| Todos | `domain` (núcleo) y `ops` (configuración, logging, métricas) |

Las reglas de dependencia entre paquetes están en
[Estructura de directorios](estructura-de-directorios.md) y se verifican en CI con
`import-linter`.
