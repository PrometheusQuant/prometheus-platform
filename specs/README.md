# specs/: especificaciones de historias grandes

Una carpeta por historia de **5 puntos o más**: `PQ-<n>-<nombre>/spec.md` (qué y por qué) y
`plan.md` (cómo). Usan el formato de las plantillas de Spec Kit, adaptado al español
([ADR-0008](../docs/adr/0008-spec-kit-solo-para-historias-grandes.md)).

- Se escriben **antes** del código y se fusionan en el mismo PR.
- El estado de la historia vive en Jira, no aquí.
